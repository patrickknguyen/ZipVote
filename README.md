# 🗳️ ZipVote
**Personalized Midterm Clarity for the Next Generation.**

ZipVote is an agent-driven platform designed to solve "ballot paralysis" for first-time voters. By entering a zip code, users receive a hyper-local, low-friction questionnaire that matches them to candidates based on actual ideological differences ("wedges").

## 🚀 The Philosophy
- **Agent-First:** We use autonomous agents to scout local races and generate questions.
- **Privacy-Lite:** No account required. Just a zip code.
- **Zero Latency:** All matching logic happens client-side to keep the experience snappy.

## 🛠️ Tech Stack
- **Environment:** Google Antigravity (Agentic Orchestration)
- **Framework:** Next.js + Tailwind CSS
- **Data Engine:** Python-based sub-agents (Scout & Wedge)

## 📍 Local Prototype (02144)
